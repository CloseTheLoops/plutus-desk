the token

your wallets

Balances for these are read by direct per-wallet query, never inferred from a ranked holder sweep — a ranked sweep saw barely a third of them on the first token measured; the direct query found all of them. Wallets already bound to your API key are added automatically, so this is for any that hold but are not bound.

contracts that are not float and not yours

burnt leaves the denominator entirely — effective supply is nominal minus burnt, and getting this wrong misprices every target. locked is staking or vesting: real supply, but not yours and not buyable. pool only if venue discovery misses a venue, which it usually does not.
Leave it blank if unsure. An ordinary third-party wallet needs no entry here — float is the residual, so anything not named is float by definition. The worksheet afterwards highlights only what actually looks misfiled: a contract rather than a wallet, or a holding big enough to move the ledger.
